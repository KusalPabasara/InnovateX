# Project Sentinel - Retail Intelligence System

## Overview

Project Sentinel is an advanced retail intelligence system designed for real-time fraud detection and operational optimization in self-checkout environments. The system integrates multiple data sources including RFID, POS transactions, computer vision, and queue monitoring to identify security threats and improve customer experience.

# SentinelX — AI-powered Fraud Detection Platform

Welcome to SentinelX (formerly Project Sentinel). This repository has been prepared for submission and packaging as the SentinelX product by Team Gmora.

SentinelX detects fraud and anomalies in self-checkout retail systems and ticketing/check-in systems (public transit). The product is localized for Sri Lanka and designed for international export.

Key artifacts are collected in the `SentinelX/` folder. The original development sources remain in `src/` for reference.

Primary pointers:

- `SentinelX/README.md` — Product overview and quick start
- `SentinelX/PROJECT_PROPOSAL.md` — Full proposal for competitions, grant bodies, and partners
- `SentinelX/VIDEO_PROMPT_VEO.txt` — VEO video generation prompt and storyboard
- `SentinelX/INSTALL.md` — Instructions to install and run the demo
